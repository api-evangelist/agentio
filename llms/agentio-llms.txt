# Agentio

> Agentio is an AI-native platform for creator advertising that connects brands with content creators across YouTube, Meta, and beyond. Its only public API surface is a hosted, remote MCP (Model Context Protocol) server — the Agentio Brand Connector at https://mcp.agentio.com/mcp — which gives a brand read-only access to its own campaigns, creator deals and deliverables, YouTube ad performance, and conversion reporting from any MCP client. Agentio publishes no REST OpenAPI, no GraphQL schema, and no developer portal.

Generated by API Evangelist (apievangelist.com) from the Agentio repo at github.com/api-evangelist/agentio. Not published by Agentio. Generated 2026-08-12.

## API surface

- [Agentio Brand Connector (MCP)](https://www.agentio.com/connector): Hosted remote MCP server at https://mcp.agentio.com/mcp. Read-only, scoped to one brand per connection. Add the URL in any MCP client that supports custom connectors, then authorize in the browser.
- [Protected resource metadata](https://mcp.agentio.com/.well-known/oauth-protected-resource/mcp): RFC 9728 document; resource https://mcp.agentio.com/mcp, authorization server https://api.agentio.com/o, scope brand-connector:read.
- [Authorization server metadata](https://api.agentio.com/.well-known/oauth-authorization-server/o): RFC 8414 document; OAuth 2.1 authorization code + refresh token, PKCE S256 required, dynamic client registration supported, public clients (no client secret).

## What the connector can and cannot do

- Can read: campaigns; creator deals and deliverables; YouTube ad performance; conversion reporting.
- Can explain: metric definitions and how Agentio workflows run.
- Cannot: change anything in the account, reach another brand's data, or act on the user's behalf.
- The live tools/list manifest is auth-gated (HTTP 401 invalid_token anonymously), so tool names and input schemas require an authenticated introspection. API Evangelist does not list tool names it has not observed.

## Getting connected

- [Connector setup guide](https://www.agentio.com/connector): add the URL, authorize, pick a brand, verify by asking the assistant to list your campaigns.
- [Sign in](https://app.agentio.com/signin)
- [Sign up](https://www.agentio.com/signup)
- Manage or disconnect: Settings -> Integrations inside the Agentio app. Disconnecting takes effect immediately. Each AI app holds one connection.
- Support: support@agentio.com or https://www.agentio.com/contact
